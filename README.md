## 🚀 The Vision

This portfolio is a digital manifestation of my engineering journey. It's built to showcase high-fidelity web experiences, focusing on performance, scalability, and cutting-edge design.

### 🛠️ Technical Arsenal

- **Frontend**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) for lightning-fast development and builds.
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) for utility-first, responsive design.
- **Animations**: [Framer Motion](https://www.framer.com/motion/) for fluid transitions and interactive micro-animations.
- **State & Routing**: [React Router Dom](https://reactrouter.com/) for seamless navigation.
- **Backend (MERN)**: Integration-ready for Node.js, Express, and MongoDB.
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/) for crisp visuals.

## 🛠️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/M-talha-mumtaz/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
